# App déstiné au dj pour trier toutes ses musiques.

## Fonctionalitée
    - Trier les musique par genre musicaux
    - renomme les musique sous forme : titre - auteur
    - supprime les doublons

## Comment utiliser ?
Séléctionez un dossier d'entrée dans lequel il y a vos musiques et des dossier de musiques.
Séléctionez un dossier de sortie.
