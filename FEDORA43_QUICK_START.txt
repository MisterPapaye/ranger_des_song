✅ STEP 1: Install System Dependencies
────────────────────────────────────

Copy and paste this command:

    sudo dnf install webkit2gtk4.1-devel libsoup3-devel glib2-devel openssl-devel


✅ STEP 2: Navigate to Project
──────────────────────────────

    cd "/home/moi/Documents/projets divers/ranger_de_song"


✅ STEP 3: Build the Project
────────────────────────────

Choose ONE:

Option A (RECOMMENDED - Automatic):
    chmod +x build-fedora43.sh
    ./build-fedora43.sh

Option B (Manual):
    cd src-tauri && rm -rf target Cargo.lock && cd ..
    rm -rf node_modules package-lock.json
    npm install
    cd src-tauri && cargo build && cd ..


✅ STEP 4: Start Development
────────────────────────────

    npm run dev

The app window will open automatically! ✨

🐛 TROUBLESHOOTING


If you get "webkit2gtk not found":
    sudo dnf install webkit2gtk4.1-devel

If you get "libsoup-3.0 not found":
    sudo dnf install libsoup3-devel

If build still fails:
    cd src-tauri
    rm -rf target Cargo.lock ~/.cargo/registry/cache
    cd ..
    npm cache clean --force
    Then run build again
