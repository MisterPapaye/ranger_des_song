🎯 WHAT THE APP DOES:

1. ✅ Scans your music folder
2. ✅ Extracts metadata (title, artist, genre)
3. ✅ Fills missing info from MusicBrainz
4. ✅ Organizes by genre (non-destructive)
5. ✅ Renames files: "Title - Artist - Genre.ext"

❓ PROBLEMS?

Build fails         → npm install && cd src-tauri && cargo clean && cargo build && cd ..
npm not found       → Install Node.js from https://nodejs.org/
cargo not found     → Install Rust from https://rustup.rs/
Permission denied   → chmod +x setup.sh && chmod +x verify.sh

See INSTALLATION.md for detailed troubleshooting.
